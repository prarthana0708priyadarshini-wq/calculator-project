# 🧮 Calculator Project

A simple and interactive calculator built with **HTML, CSS, and JavaScript**.

## 🎯 How to Use
1. Clone or download this repository  
2. Open `index.html` in your web browser  
3. Use mouse clicks or keyboard to perform calculations  
4. Press 'AC' to clear, 'DEL' to delete last digit  

## ⌨️ Keyboard Shortcuts
- Numbers: 0–9  
- Operations: +, -, *, /  
- Decimal: .  
- Equals: Enter or =  
- Clear: Escape  
- Delete: Backspace
